# 🌿 HabitTrack — Daily Habit Tracker

A simple, responsive, and user-friendly habit tracker built to help users develop consistent daily routines and build better habits.

🔗 **Live Demo:** https://rakshana1708.github.io/HabitTrack/

## ✨ Features

- ➕ Add custom daily habits
- ✅ Mark habits as completed
- 🗑️ Delete habits when no longer needed
- 📊 Track daily progress with a progress bar
- 📈 View total and completed habit counts
- 💾 Automatically save habits using browser Local Storage
- 📱 Responsive design for desktop and mobile devices
- 🌱 Clean and minimal sage-green user interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Habit tracking and progress calculations
- **Local Storage** — Saving habits in the browser
- **GitHub Pages** — Free website hosting

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rakshana1708/HabitTrack.git
   ```

2. Open the project folder:

   ```bash
   cd HabitTrack
   ```

3. Open `index.html` in your web browser.

No additional software installation is required to run the basic website.
